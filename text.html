Understanding HTML & Text Formatting

HTML (HyperText Markup Language) is the foundation of web pages. It defines how content is structured and presented on the internet. With HTML, we can create headings, paragraphs, links, lists, tables, forms, and much more.

What is HTML?

HTML stands for HyperText Markup Language. It uses tags to describe the structure of web pages. Every web document starts with a <!DOCTYPE html> declaration and is enclosed between <html> and </html> tags.

Example of a Basic HTML Document:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my first HTML page.</p>
  </body>
</html>

Text Formatting Elements

HTML offers various tags for styling and emphasizing text meaningfully.

Common Formatting Tags:

Bold — visually bold text.
Strong — important or serious content.
Italic — adds a stylistic emphasis.
Emphasis — indicates stress in meaning.
Underline — highlights text visually.
Small — for fine print or side notes.
Marked — highlights or draws attention.
Strikethrough — shows incorrect or outdated content.
Inserted — newly added content.
Deleted — removed content.
